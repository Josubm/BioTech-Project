# BioTech-Project

Landing page del proyecto BioTech para Ingeniería Aplicada.

## Publicación

El sitio es estático y su entrada es `index.html`. Está preparado para
publicarse con GitHub Pages desde la rama `main` y la carpeta raíz.

URL pública esperada:

`https://josubm.github.io/BioTech-Project/`

Para actualizarlo:

1. Modifica `index.html`.
2. Confirma y sube los cambios a `main`.
3. GitHub Pages publicará automáticamente la nueva versión.

El formulario de contacto es demostrativo y no envía datos a un servidor.
